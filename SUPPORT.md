# Getting help

## Questions

Ask in [GitHub Discussions](https://github.com/openadviser/ai-catalog/discussions). That is the place
for "how do I use this?", "how is this price meant to be read?" and ideas that are not yet a proposal.
Please read the [documentation](docs/) and the [README](README.md) first.

## The issue tracker

Use [issues](https://github.com/openadviser/ai-catalog/issues/new/choose) for work that someone can act
on:

- a wrong or missing price (with the page URL and the date you read it);
- a new model or provider;
- a broken reader;
- a bug in a client;
- a feature request.

Blank issues are turned off. Pick the form that fits.

## Security

Do not report vulnerabilities in public. See [SECURITY.md](SECURITY.md).

## Other

This is a community project with no service-level commitments. The provider's invoice is always
authoritative for what you were charged.
